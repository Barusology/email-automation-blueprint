# Email Automation Blueprint — Sales Page

## Quick Start
1. Add your PDF to `files/email-automation-blueprint.pdf`
2. Run `npm install`
3. Run `node server.js`
4. Open http://localhost:3000

## Going Live
- Replace test Paystack keys with live keys in `.env` and `public/script.js`
- Deploy to Railway, Render, or any Node.js host
